# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

A ride-pooling MVP for Dhaka's three-seat battery "Teslas". Passengers (Nusrat, Rafiq, Shirin)
request rides and share a Tesla when their routes are compatible; the driver (Jashim, with his
Tesla **Bullet**) sees who is on board and moves the trip through its lifecycle.

Work in progress — the full README is written once the MVP is integrated.
